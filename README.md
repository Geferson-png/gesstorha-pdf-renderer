# Gesstorha PDF Renderer

Renderizador público e isolado para converter o certificado HTML Visual V3 em PDF usando Chromium/Playwright.

## Segurança

Este repositório não contém planilhas, IDs internos, credenciais, tokens ou código do sistema principal. A URL do certificado é fornecida somente no disparo manual do workflow.

## Teste

Abra **Actions > Testar PDF Visual V3 > Run workflow** e informe a URL completa do certificado. O PDF resultante fica disponível como artifact por 1 dia.

O repositório principal de certificados permanece privado.
